# AeroCalc

Calculadora educacional de desempenho de aeronaves desenvolvida com HTML, CSS e JavaScript.

## Funcionalidades

- Cálculo de autonomia total
- Cálculo de autonomia útil
- Cálculo de alcance estimado
- Cálculo do combustível de reserva
- Interface responsiva
- Validação dos dados informados

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

## Aviso

Este projeto possui finalidade exclusivamente educacional. Os resultados não devem ser utilizados no planejamento ou na operação de voos reais.
